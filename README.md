# 智能文件重命名工具

## 项目概述

**项目名称**：智能文件重命名工具  
**目标用户**：私募基金运维人员  
**使用环境**：企业内网环境  
**核心价值**：基于AI和OCR的智能文件重命名，提高运维效率  

## 功能需求

### 核心功能
- ✅ **智能文件重命名**：基于文件内容智能分析
- ✅ **多文件类型支持**：图片、PDF、文档等
- ✅ **OCR文字识别**：图片文件OCR + PDF扫描件转图片OCR
- ✅ **批量处理**：支持多个文件同时重命名
- ✅ **存储模式选择**：复制模式（保留原文件）+ 覆盖模式

### 技术规格
- ✅ **OCR多语言支持**：中文优先，支持多语言识别
- ✅ **并发控制**：批量处理时最多同时处理100个文件
- ✅ **文件大小限制**：单文件不能超过100MB
- ✅ **错误处理策略**：失败跳过，在执行结果中详细记录失败原因
- ✅ **进度显示**：详细的进度条和操作状态反馈

### 用户界面
- ✅ **三个主要标签页**：重命名操作、配置选项、执行结果
- ✅ **现代化UI设计**：简洁、直观的操作界面
- ✅ **运维友好设计**：清晰的操作状态显示和错误诊断

### 部署要求
- ✅ **跨平台支持**：macOS + Windows
- ✅ **双击执行**：无需安装，直接运行
- ✅ **独立可执行文件**：打包成.app/.exe格式
- ✅ **无外部依赖**：所有功能内置

## 技术栈

### 核心框架
- **Electron 28+**：跨平台桌面应用框架
- **React 18+**：现代化UI开发
- **TypeScript 5+**：类型安全和开发体验

### 前端技术
- **UI组件库**：Ant Design（企业级组件）
- **状态管理**：Zustand（轻量级状态管理）
- **样式方案**：Tailwind CSS + CSS Modules
- **图标库**：Lucide React

### 后端服务
- **Node.js 18+**：JavaScript运行时
- **Express.js**：轻量级Web框架
- **文件处理**：Node.js原生fs模块 + fs-extra

### OCR和文件处理
- **OCR引擎**：Tesseract.js（纯JavaScript，跨平台兼容）
- **图片处理**：Sharp（高性能图片处理库）
- **PDF处理**：pdf-lib（PDF操作）+ pdf2pic（PDF转图片）
- **文件类型检测**：file-type（精确文件类型识别）

### AI集成
- **DeepSeek API**：HTTP客户端（axios）
- **文本处理**：自然语言处理工具库

### 开发工具
- **构建工具**：Vite（快速开发构建）
- **打包工具**：Electron Builder
- **代码质量**：ESLint + Prettier
- **测试框架**：Jest + Testing Library

## 代码管理策略

### 分支结构
```
main (主分支) - 生产环境代码，保持稳定
├── develop (开发分支) - 日常开发、功能开发、bug修复
├── release (发布分支) - 代码稳定后，准备发布
└── hotfix (热修复分支) - 紧急bug修复
```

### 分支保护规则
- **develop分支**：需要PR审查，禁止直接推送
- **release分支**：只允许从develop分支合并
- **main分支**：只允许从release分支合并

### 开发工作流程
1. **功能开发**：从develop分支创建功能分支
2. **代码审查**：通过Pull Request合并到develop
3. **发布准备**：从develop创建release分支
4. **构建发布**：在release分支推送标签触发构建
5. **生产部署**：构建成功后合并到main分支

## 自动化打包构建

- **触发条件**：只在release分支推送版本标签时触发

- **自动化发布**：构建完成后自动创建GitHub Release
- **多平台支持**：生成.app和.exe安装包

### 构建流程
```
代码推送 → 创建版本标签 → 触发GitHub Actions → 并行构建 → 自动发布
```

### 本地开发
- **开发环境**：macOS
- **本地测试**：可测试macOS版本功能
- **跨平台构建**：通过GitHub Actions自动构建Windows版本
